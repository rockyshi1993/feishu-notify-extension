# 飞书通知扩展（Grok Bot 版）

Chrome MV3 扩展：监测飞书网页（`*.feishu.cn`）的新消息，过滤、合并后推送到 Grok Bot 接收地址，由助手去飞书读取并汇总。

**只通知**：不发飞书消息、不改多维表格、不调用飞书内部接口；只读取页面上看得到的通知标题和正文、标签页未读数，以及当前打开会话的最近消息（尽力读取）。

## 安装（加载已解压的扩展程序）
1. 运行 `sh scripts/build.sh`（也可以直接用仓库根目录）。
2. 打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选 `dist/feishu-notify-extension`。
3. 打开扩展「设置」，填 Grok Bot 接收地址和密钥 →「Save」（Chrome 会请求访问该域名）→「Send test push」，看到 `Test OK (HTTP 200…)` 即成功。
4. 保持一个已登录的飞书网页标签页开着；Chrome 关闭或休眠期间的消息抓不到（靠助手的定时检查兜底）。

## 规则
- 工作时间（默认周一至五 09:00–18:30，Asia/Shanghai）内，消息先等 2 分钟合并，每次最多推 20 条；命中优先关键词或 @我 的消息立即推，并排在最前。
- 下班时间一律排队（命中关键词的也排队），到上班时间合并推送。
- 10 分钟内相同的消息去重；队列上限 200 条，满了丢最旧的，并在下次推送里写明 `droppedCount`。
- 推送失败 30 秒后重试 1 次，还失败就继续留在队列里；返回 401/403 时暂停自动推送，等重新保存设置或测试推送成功后恢复。
- 免打扰群跟随飞书，不推；当前前台正打开的会话来消息不推；机器人（如多维表格助手）的消息放行并打 `bot` 标记。

推送格式、全部设置项和已知限制见英文 [README.md](README.md)。

## 隐私
密钥只存在 `chrome.storage.local`，界面上打码显示，不导出、不写日志。消息原文只在本地保留最近 20 条日志，只发往你填的接收地址；关掉「Include message text」后只推会话名和条数。
